# E-Portfolio — ชื่อ นามสกุล

แฟ้มสะสมงานอิเล็กทรอนิกส์ รายวิชาวิทยาการคำนวณ ม.6
เว็บไซต์แบบ Static (HTML/CSS/JavaScript) เผยแพร่ผ่าน GitHub Pages

**เว็บไซต์:** https://USERNAME.github.io/e-portfolio/

## เกี่ยวกับโปรเจกต์
เว็บไซต์แนะนำตัว ทักษะ ผลงาน และกิจกรรม ใช้ AI ช่วยร่างโครงสร้างและโค้ดเริ่มต้น จากนั้นผู้จัดทำกำหนดเนื้อหา ตรวจสอบ และปรับปรุงด้วยตนเอง

## โครงสร้างไฟล์
```
e-portfolio/
├── index.html              หน้าหลัก (มีสไตล์และสคริปต์ในไฟล์เดียว)
├── projects/
│   └── calculator.html     ผลงานโค้ด: เครื่องคิดเลขค่าใช้จ่าย
├── assets/                 รูปภาพ (เช่น photo.jpg)
└── README.md
```

## ผลงานโค้ด
| ผลงาน | คำอธิบาย | เทคโนโลยี |
|---|---|---|
| [เครื่องคิดเลขค่าใช้จ่าย](projects/calculator.html) | เพิ่ม/ลบรายการ และคำนวณยอดรวมอัตโนมัติ | HTML, CSS, JavaScript |

## วิธีเผยแพร่
1. สร้าง Public repository ชื่อ `e-portfolio`
2. Add file → Upload files แล้วอัปโหลดทุกไฟล์และโฟลเดอร์ → Commit changes
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save

## การอ้างอิงและความปลอดภัยข้อมูล
- ใช้ AI (ระบุชื่อเครื่องมือ) ช่วยร่างโค้ด และตรวจแก้โดยผู้จัดทำ
- ฟอนต์ IBM Plex Sans Thai (SIL Open Font License) จาก Google Fonts
- ไม่เผยแพร่ข้อมูลอ่อนไหว เช่น เลขบัตรประชาชน ที่อยู่ หรือเบอร์โทรส่วนตัว
