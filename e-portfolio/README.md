# E-Portfolio — ชื่อ นามสกุล

แฟ้มสะสมงานอิเล็กทรอนิกส์ รายวิชาวิทยาการคำนวณ ม.6
เว็บไซต์แบบ Static (HTML/CSS/JavaScript) เผยแพร่ผ่าน GitHub Pages

**เว็บไซต์:** https://phisutsin13.github.io/portfolio/

## เกี่ยวกับโปรเจกต์
เว็บไซต์แนะนำตัว ทักษะ ผลงาน และกิจกรรม ใช้ AI ช่วยร่างโครงสร้างและโค้ดเริ่มต้น จากนั้นผู้จัดทำกำหนดเนื้อหา ตรวจสอบ และปรับปรุงด้วยตนเอง

## โครงสร้างไฟล์
```
e-portfolio/
├── index.html              หน้าหลัก (มีสไตล์และสคริปต์ในไฟล์เดียว)
├── projects/
│   └── calculator.html     ผลงานโค้ด: เครื่องคิดเลขค่าใช้จ่าย
├── assets/                 รูปภาพ (เช่น photo.jpg)
└── README.md
```
