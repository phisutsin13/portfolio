## เว็บไซต์นี้คืออะไร

เว็บไซต์หน้าเดียว (single page) ที่รวบรวมข้อมูลของผู้จัดทำไว้ในที่เดียว ได้แก่ การแนะนำตัว ทักษะ ผลงาน กิจกรรม และช่องทางติดต่อ ใช้ส่งเป็นงานวิชาวิทยาการคำนวณ และให้ครูหรือเพื่อน ๆ เปิดดูผ่านเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งอะไร

**จุดเด่น**

- เป็นเว็บ Static ไฟล์เดียว ไม่ต้องใช้ฐานข้อมูลหรือเซิร์ฟเวอร์
- ใช้งานได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ (Responsive) มีเมนูแบบพับได้บนจอเล็ก
- มีแถบความคืบหน้าการเลื่อนหน้า ปุ่มกลับขึ้นด้านบน และเมนูที่ไฮไลต์ส่วนที่กำลังดูอยู่
- รองรับการเข้าถึง (Accessibility) เช่น ลิงก์ "ข้ามไปยังเนื้อหาหลัก" การใช้คีย์บอร์ดนำทาง และเคารพการตั้งค่าลดแอนิเมชันของระบบ (`prefers-reduced-motion`)

## โครงสร้างไฟล์

```text
portfolio/
├── index.html        # หน้าเว็บทั้งหมด (เนื้อหา + CSS + JavaScript)
├── assets/
│   └── profile.jpg   # รูปโปรไฟล์
└── README.md         # ไฟล์นี้
```

ส่วนต่าง ๆ ภายใน `index.html`

- `<style>` — สไตล์ทั้งหมด ค่าสีและฟอนต์ตั้งไว้ที่ตัวแปรใน `:root` ด้านบนสุด
- `<main>` — เนื้อหาแบ่งเป็น `section` ตาม id: `#home`, `#about`, `#projects`, `#activities`, `#contact`
- `<script>` ท้ายไฟล์ — เมนูมือถือ แถบความคืบหน้า ปุ่มกลับขึ้นด้านบน แอนิเมชันตอนเลื่อนหน้า และการไฮไลต์เมนู

## วิธีเปิดดูในเครื่อง

ไม่ต้องติดตั้งโปรแกรมเพิ่ม

**วิธีที่ 1: เปิดไฟล์โดยตรง (ง่ายที่สุด)**

ดาวน์โหลดหรือโคลนโปรเจกต์ แล้วดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์

```bash
git clone https://github.com/phisutsin13/portfolio.git
cd portfolio
```

**วิธีที่ 2: รันเซิร์ฟเวอร์จำลอง (ใกล้เคียงของจริงกว่า)**

ถ้ามี Python ติดตั้งอยู่ ให้รัน

```bash
python3 -m http.server 8000
```

จากนั้นเปิด http://localhost:8000 ในเบราว์เซอร์ (กด `Ctrl + C` ที่เทอร์มินัลเพื่อหยุด)

## วิธีแก้ไขเนื้อหา

เปิด `index.html` ด้วยโปรแกรมแก้ไขข้อความ (เช่น VS Code) แล้วค้นหาข้อความที่ต้องการแก้

| ต้องการแก้ | ให้ดูที่ |
|---|---|
| ชื่อและข้อความแนะนำตัว | ส่วน `<!-- hero -->` และ `<!-- about + skills -->` |
| รูปโปรไฟล์ | แทนที่ไฟล์ `assets/profile.jpg` (ใช้ชื่อเดิม อัตราส่วนภาพประมาณ 4:5) |
| คะแนนทักษะ | แก้ค่า `--v` และตัวเลข `pct` ในแต่ละ `<li>` ของ `.skills` เช่น `style="--v:80%"` กับ `<span class="pct">80</span>` |
| ผลงาน | ส่วน `<!-- projects -->` แก้ชื่อ คำอธิบาย เทคโนโลยี และลิงก์ในการ์ด |
| กิจกรรม | ส่วน `<!-- activities -->` คัดลอก `<li class="reveal">` ไปเพิ่มรายการใหม่ |
| ช่องทางติดต่อ | ส่วน `<!-- contact -->` |
| สีและฟอนต์ | ตัวแปรใน `:root { ... }` ที่ต้นไฟล์ เช่น `--gold` (สีทอง) `--bg` (พื้นหลัง) |

**ตัวอย่าง: เพิ่มกิจกรรมใหม่** — คัดลอกบล็อกนี้ไปวางในรายการ `<ul class="timeline">`

```html
<li class="reveal">
  <span class="when">พ.ศ. 2569</span>
  <div>
    <b>ชื่อกิจกรรม</b>
    <p>รายละเอียดสั้น ๆ ว่าทำอะไรและได้เรียนรู้อะไร</p>
  </div>
</li>
```

หลังแก้ไข ให้เปิดดูผลในเบราว์เซอร์ และลองย่อหน้าต่างให้เล็กเพื่อตรวจหน้าตาบนมือถือด้วย

## วิธีเผยแพร่ด้วย GitHub Pages

1. อัปโหลดโค้ดขึ้น GitHub (push ขึ้นสาขา `main`)

```bash
git add .
git commit -m "อัปเดตเนื้อหา"
git push origin main
```

2. ไปที่ **Settings → Pages** ของ repository
3. ที่ **Build and deployment** เลือก Source เป็น **Deploy from a branch**
4. เลือกสาขา `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

ทุกครั้งที่ push การแก้ไขใหม่ GitHub Pages จะอัปเดตเว็บให้อัตโนมัติ
