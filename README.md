# E-Portfolio 

แฟ้มสะสมงานอิเล็กทรอนิกส์ รายวิชาวิทยาการคำนวณ ม.6

**เว็บไซต์:** https://phisutsin13.github.io/portfolio/

## เกี่ยวกับโปรเจกต์
เว็บไซต์นี้แนะนำตัว ทักษะ ผลงาน และกิจกรรมของผู้จัดทำ สร้างด้วย HTML, CSS และ JavaScript แบบ Static และเผยแพร่ผ่าน GitHub Pages โดยใช้ AI ช่วยร่างโครงสร้างและโค้ดเริ่มต้น จากนั้นผู้จัดทำตรวจสอบ แก้ไข และปรับปรุงเนื้อหาด้วยตนเอง

## ผลงาน
| ผลงาน | คำอธิบาย | เทคโนโลยี | ลิงก์ |

### การทำงานของ Bahtwise โดยสังเกต
- ผู้ใช้สมัครและเข้าสู่ระบบก่อนใช้งาน
- บันทึกรายการค่าใช้จ่ายและดูยอดรวม
- ข้อมูลเก็บในฐานข้อมูล Supabase
